# 🚀 Interactive Product Inventory & Analytics Dashboard

A JavaScript-based mini project that demonstrates core JavaScript concepts through a practical product inventory management and analytics application.

The application allows users to add products, validate input data, categorize products based on price, search inventory, calculate financial statistics, and generate formatted inventory reports.

## 📌 Project Overview

The **Interactive Product Inventory & Analytics Dashboard** is a console-based application developed to practice and implement fundamental JavaScript concepts in a real-world scenario.

It combines data handling, conditional statements, loops, functions, scope, and array methods into one integrated project.

## ✨ Features

- **Product Management:** Add new products using browser `prompt()`.
- **Input Validation:** Validate product names and prices using conditional statements.
- **Product Categorization:** Automatically classify products into Budget, Standard, and Premium categories.
- **Product Search:** Search for products using loops and conditional statements.
- **Inventory Analytics:** Calculate the total inventory value.
- **Discount & Tax Calculation:** Apply custom discount and tax rates.
- **Affordable Products Filter:** Find products below a specified price.
- **Formatted Reports:** Generate uppercase product summaries.

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YourUsername/Inventory-Analytics-Dashboard.git
```

### 2. Open the Project

Open the project folder in Visual Studio Code.

### 3. Install Live Server

- Open VS Code Extensions.
- Search for **Live Server**.
- Install the extension by Ritwick Dey.

### 4. Run the Application

- Open `index.html` in VS Code.
- Click the **Go Live** button.
- The application will open in your browser.
- Open Chrome Developer Tools using `Ctrl + Shift + J`.
- Follow the prompts to enter product details.
